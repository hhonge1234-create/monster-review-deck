# 《괴물》 리뷰 데이터 분석 Slide Deck (v2)

고레에다 히로카즈 《괴물》(Monster, 2023) 왓챠 관객 리뷰 477건 분석 프레젠테이션.
리포트의 결론 *"괴물을 찾으러 갔다가 나 자신을 발견하고, 위로받고 돌아온다"* 를 3막(질문 → 발견 → 위로) 18장으로 구성.

- 애니메이션: anime.js · 그래프: Chart.js · matplotlib(길이 분포, 워드클라우드, 감정 흐름 GIF) · manim(시점 전환 영상)
- 이동: ← → 키, 스와이프, 클릭, 휠 · `#번호`로 특정 슬라이드 열기
- 이전 버전: `/prev`, `/v18`, `/old`
- 계획서·차트/영상 생성 스크립트: `tools/`

```
python3 -m http.server
```
