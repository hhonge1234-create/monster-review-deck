# 《괴물》 리뷰 분석 Deck v2 — 새 구성 계획

## 0. 원칙
- **리포트가 뼈대**: 리포트 결론 한 줄 — *"괴물을 찾으러 갔다가 나 자신을 발견하고, 위로받고 돌아온다"* — 를 덱 전체의 3막 구조로 사용한다.
  - 1막 **질문** (괴물을 찾으러) → 2막 **발견** (시선·오해·구조 = 나 자신) → 3막 **위로** (결말·음악·사랑)
  - 영화 자체의 3부(엄마→담임→아이들) 구성과 겹쳐지게 막 전환 슬라이드를 둔다.
- **제목 = 그 슬라이드의 결론 문장**. 차트는 슬라이드당 하나, 같은 그래프 중복 금지.
- **수치는 리포트 기준**(테마 건수·키워드 표). 길이 분포만 원본 JSON에서 재계산(92/156/121/66/42, 합 477).
- **톤**: 밝은 종이색 + 이끼/숲 녹색 + 햇살 노랑 + 포스터 레드(괴물 로고). 어둡지 않게, 영화 사진은 풀블리드 + 부드러운 스크림.
- **사진**: 기존 업로드 사진 사용 — `assets/film/{field_run_clean,train,poster}`, `assets/img/{forest,sunforest,canopy,moss,meadow,water}`.

## 2. 시각화 산출물
- matplotlib: `charts/length_dist.png`, `charts/wordcloud.png`, `charts/emotion_flow.gif`
- manim: `charts/viewpoints.mp4` (한 사건 → 엄마/담임/아이들 3개의 해석) — 설치 실패 시 anime.js SVG로 대체
- Chart.js: 키워드 막대, 비판 누적 막대 / anime.js: 버블, 링, 파이프라인, 네트워크, 파형

## 3. 검증 루프
1. `node --check js/*.js`
2. 로컬 서버 → 모든 에셋 HTTP 200
3. 헤드리스 Chrome으로 16장 전부 스크린샷 (`#n`, 애니메이션 완료 상태) → 직접 눈으로 검토
4. 문제(겹침/잘림/빈 차트/콘솔 에러) 수정 → 3번 재실행, 문제 0이 될 때까지
5. 배포 후 Pages URL에서 다시 스크린샷 확인
